# Day 3 — Mobile AI UX Patterns

## Objective
Translate AI capabilities into clear, reliable mobile interactions.

## Deliverables
- 5 mini user flows
- AI-to-UI response contract for each use case
- Loading, empty, error, retry, and low-confidence states
- Fallback behaviour for every flow

## Use Cases
1. Chat
2. Smart Search
3. Extraction
4. Recommendation
5. Assistant / Form Help

## Definition of Done
- No flow depends on displaying uncontrolled raw model text.
- Every flow includes an error/fallback state.
